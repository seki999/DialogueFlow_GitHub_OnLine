# 混合云网络接入：VPN与FastConnect

企业设备网络需要通过专线或隧道稳定接入OCI，才能让监控平台访问到设备。

```mermaid
flowchart LR
    DEVNET[企业设备网络] --> VPNORFC[IPSec VPN / FastConnect]
    VPNORFC --> DRG[OCI DRG]
    DRG --> VCN[OCI VCN]
    VCN --> OKE[OKE Pod]
```

## 核心要点

* IPSec VPN适合较小带宽、快速搭建的场景
* FastConnect提供更稳定、专线级别的连接
* DRG（Dynamic Routing Gateway）是VCN与外部网络对接的核心枢纽
* 接入完成后还需处理往返路由、防火墙放行等问题

---

## 本章测验

本章共 5 道单项选择题。

### 第 1 题

IPSec VPN与FastConnect相比，通常的特点是什么？

- A. IPSec VPN搭建较快但通常不如FastConnect稳定
- B. IPSec VPN是物理专线，FastConnect是隧道
- C. 两者完全没有区别
- D. FastConnect只能用于测试环境

<details>
<summary>选择答案后查看结果</summary>

正确答案：A

答案解析：IPSec VPN基于互联网隧道，搭建相对快速，而FastConnect提供专线级别的连接，通常更稳定。

</details>

### 第 2 题

DRG在OCI网络架构中的作用是什么？

- A. 存储Oracle数据库数据
- B. 作为VCN与外部网络对接的动态路由枢纽
- C. 运行Spring Boot容器
- D. 接收SNMP Trap

<details>
<summary>选择答案后查看结果</summary>

正确答案：B

答案解析：DRG（Dynamic Routing Gateway）是VCN对接VPN、FastConnect等外部网络的核心路由组件。

</details>

### 第 3 题

企业设备网络接入OCI后，还需要额外处理什么问题？

- A. 无需处理任何额外问题
- B. 只需要考虑Java版本兼容性
- C. 往返路由是否打通、防火墙是否放行等
- D. 只需要考虑数据库表结构

<details>
<summary>选择答案后查看结果</summary>

正确答案：C

答案解析：接入完成只是第一步，还需要确保路由双向可达，以及防火墙规则允许相应流量通过。

</details>

### 第 4 题

为什么TCP Ping和SNMP GET需要重点关注往返路由问题？

- A. 因为它们不涉及网络通信
- B. 因为它们只使用本地回环地址
- C. 因为SNMP GET不需要网络
- D. 因为它们需要从OKE访问设备网段，也需要设备网段能把回包送回来

<details>
<summary>选择答案后查看结果</summary>

正确答案：D

答案解析：SNMP GET等操作需要发出请求并接收设备的回包，如果往返路由未打通，会导致超时或无法获取数据。

</details>

### 第 5 题

下列哪一项最能概括本章描述的网络接入链路？

- A. 企业设备网络 → IPSec VPN/FastConnect → OCI DRG → OCI VCN
- B. 企业设备网络 → OCIR → OKE
- C. 企业设备网络 → Oracle数据库 → Vault
- D. 企业设备网络直接连接Spring Boot Pod

<details>
<summary>选择答案后查看结果</summary>

正确答案：A

答案解析：企业设备网络通过VPN或FastConnect接入DRG，再进入VCN，这是本章描述的标准接入链路。

</details>
