# 训练模型在做什么：从数据到损失函数

训练模型的本质是：找到一组参数，使模型预测结果与真实答案之间的误差尽可能小。

```mermaid
flowchart LR
    A[前向传播] --> B[计算损失]
    B --> C[反向传播]
    C --> D[更新参数]
    D --> A
```

## 核心要点

* 模型用参数 w、b 把输入 x 映射为预测值 y_hat
* 损失函数 L 衡量预测值与真实值 y 的差距，例如均方误差
* 反向传播计算损失对每个参数的偏导数
* 参数沿着让损失下降的方向更新：`w = w - lr * dL/dw`
* 这四步不断重复，参数逐渐逼近合理值

## 房价预测示例

```text
50㎡  → 3000万日元
70㎡  → 4200万日元
90㎡  → 5500万日元
```

模型：y_hat = w*x + b，一开始 w、b 是随机值，预测很差，损失很大；
经过多轮“前向传播 → 计算损失 → 反向传播 → 更新参数”，损失逐渐变小。

## 本章测验

### 第 1 题

训练模型的本质是什么？

- A. 记住所有训练数据
- B. 找到一组参数，使预测结果与真实答案的误差尽可能小
- C. 让模型运行得更快
- D. 让模型占用更少内存

<details>
<summary>选择答案后查看结果</summary>

正确答案：B

答案解析：训练的目标是通过不断调整参数，让损失函数（预测值与真实值的误差）尽可能小，而不是单纯记忆数据、追求速度或节省内存。

</details>

### 第 2 题

在“前向传播 → 计算损失 → 反向传播 → 更新参数”这个循环中，反向传播的作用是什么？

- A. 生成训练数据
- B. 计算损失对每个参数的偏导数（梯度）
- C. 直接修改模型结构
- D. 打乱训练数据顺序

<details>
<summary>选择答案后查看结果</summary>

正确答案：B

答案解析：反向传播利用链式法则，计算损失函数相对于每个参数的梯度，为后续的参数更新提供方向和幅度依据。

</details>

### 第 3 题

参数更新公式 `w = w - lr * dL/dw` 中，lr 起什么作用？

- A. 决定训练数据的数量
- B. 决定每次参数更新的步长
- C. 决定模型的层数
- D. 决定损失函数的类型

<details>
<summary>选择答案后查看结果</summary>

正确答案：B

答案解析：lr（学习率）控制每次沿梯度方向更新参数时迈出的步子大小，是训练中最重要的超参数之一。

</details>

### 第 4 题

在房价预测例子中，如果一开始 w、b 是随机设置的值，模型的初始预测通常会怎样？

- A. 立刻完全准确
- B. 很不准确，需要通过训练逐步调整
- C. 完全不产生输出
- D. 自动等于真实房价的平均值

<details>
<summary>选择答案后查看结果</summary>

正确答案：B

答案解析：随机初始化的参数并不包含数据规律，因此初始预测通常偏差很大，需要通过多轮训练循环逐步逼近合理值。

</details>

### 第 5 题

下面哪一项正确描述了训练循环中四个步骤的顺序？

- A. 更新参数 → 计算损失 → 前向传播 → 反向传播
- B. 计算损失 → 前向传播 → 更新参数 → 反向传播
- C. 前向传播 → 计算损失 → 反向传播 → 更新参数
- D. 反向传播 → 更新参数 → 前向传播 → 计算损失

<details>
<summary>选择答案后查看结果</summary>

正确答案：C

答案解析：正确顺序是先用当前参数做前向传播得到预测值，再计算损失，然后反向传播得到梯度，最后用梯度更新参数，如此循环。

</details>
