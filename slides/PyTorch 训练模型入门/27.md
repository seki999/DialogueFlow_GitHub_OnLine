# CNN：图像模型的基础

全连接网络会忽略图像的空间结构，CNN 用卷积核提取空间特征。

```mermaid
flowchart LR
    A["输入图像 N,C,H,W"] --> B["Conv2d + BatchNorm2d + ReLU"]
    B --> C[MaxPool2d 下采样]
    C --> D["Conv2d + BatchNorm2d + ReLU"]
    D --> E[MaxPool2d 下采样]
    E --> F[Flatten]
    F --> G[全连接分类头]
```

## 核心要点

* CNN 通过卷积核提取边缘、纹理、形状、局部结构、高级语义等特征
* 输入形状约定为 `[batch_size, channels, height, width]`，例如 MNIST 为 `[128, 1, 28, 28]`
* `nn.Conv2d(in_channels, out_channels, kernel_size, padding)`：卷积层，`out_channels` 决定提取多少种特征
* `nn.MaxPool2d(2)`：下采样，减小特征图尺寸，降低计算量并增强平移不变性
* 典型结构：多组 `Conv2d + BatchNorm2d + ReLU + MaxPool2d` 堆叠提取特征，最后 `Flatten` 后接全连接层完成分类

## 代码示例

```python
class SimpleCnn(nn.Module):
    def __init__(self, number_of_classes=10):
        super().__init__()
        self.features = nn.Sequential(
            nn.Conv2d(1, 32, kernel_size=3, padding=1),
            nn.BatchNorm2d(32),
            nn.ReLU(),
            nn.MaxPool2d(2),

            nn.Conv2d(32, 64, kernel_size=3, padding=1),
            nn.BatchNorm2d(64),
            nn.ReLU(),
            nn.MaxPool2d(2),
        )
        self.classifier = nn.Sequential(
            nn.Flatten(),
            nn.Linear(64 * 7 * 7, 128),
            nn.ReLU(),
            nn.Dropout(0.3),
            nn.Linear(128, number_of_classes),
        )

    def forward(self, x):
        x = self.features(x)
        return self.classifier(x)
```

## 本章测验

### 第 1 题

为什么全连接网络处理图像时会有局限？

- A. 全连接网络无法处理彩色图像
- B. 全连接网络会忽略图像的空间结构信息
- C. 全连接网络运行速度总是比 CNN 慢
- D. 全连接网络不能用于分类任务

<details>
<summary>选择答案后查看结果</summary>

正确答案：B

答案解析：全连接层把图像展平成一维向量输入，丢失了像素之间的空间位置关系，而 CNN 通过卷积核直接在二维空间上提取局部特征，更适合图像任务。

</details>

### 第 2 题

图像任务中常见的输入形状 `[N, C, H, W]`，其中 C 代表什么？

- A. 批次大小
- B. 通道数，例如灰度图为 1、彩色图为 3
- C. 图像高度
- D. 图像宽度

<details>
<summary>选择答案后查看结果</summary>

正确答案：B

答案解析：[N, C, H, W] 分别代表批次大小、通道数、高度、宽度，其中 C 是通道数，比如灰度图通常是 1 个通道，RGB 彩色图是 3 个通道。

</details>

### 第 3 题

`nn.MaxPool2d(2)` 在 CNN 中的主要作用是什么？

- A. 增加图像的通道数
- B. 对特征图进行下采样，减小尺寸
- C. 计算损失函数
- D. 更新模型参数

<details>
<summary>选择答案后查看结果</summary>

正确答案：B

答案解析：MaxPool2d 会在局部窗口内取最大值，从而对特征图进行下采样，减小特征图的空间尺寸，同时降低后续计算量。

</details>

### 第 4 题

在示例 CNN 结构中，从 `features` 部分输出后接 `Flatten`，这一步的目的是什么？

- A. 把多维特征图展平成一维向量，才能输入全连接层
- B. 增加图像的分辨率
- C. 对图像做数据增强
- D. 计算模型的准确率

<details>
<summary>选择答案后查看结果</summary>

正确答案：A

答案解析：卷积部分输出的是多维特征图 [N, C, H, W]，而全连接层 nn.Linear 要求输入是二维 [N, features]，所以需要用 Flatten 把后面几维展平成一维。

</details>

### 第 5 题

在卷积层之后紧跟 BatchNorm2d 和 ReLU 的常见组合中，各自的作用分别是什么？

- A. BatchNorm2d 负责非线性变换，ReLU 负责归一化
- B. BatchNorm2d 负责让训练更稳定，ReLU 引入非线性表达能力
- C. 两者作用完全相同，可以互相替代
- D. BatchNorm2d 和 ReLU 都用于减少模型参数量

<details>
<summary>选择答案后查看结果</summary>

正确答案：B

答案解析：BatchNorm2d 通过归一化激活值分布让训练更稳定、收敛更快；ReLU 则为网络引入非线性表达能力，两者作用互补，常常配合使用。

</details>
