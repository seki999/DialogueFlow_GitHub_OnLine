# PyTorch 模型训练：从入门到精通 —— 课程说明

## 课程主题

本课程基于《PyTorch 模型训练：从入门到精通》一文整理制作，覆盖从 Tensor 基础、
Autograd 自动微分、标准训练循环，到分类模型、正则化、归一化、梯度问题、GPU 训练、
混合精度、模型保存恢复、CNN、迁移学习、训练问题诊断，直至课程总结与进阶方向的完整
知识体系，适合已有 Python 基础和大学数学基础的学习者。

## 总章节数

共 **30** 组文件（编号 01 至 30），属于“长”版本课程，适合完整技术课程学习。

## 文件使用方式

每一章由两个同名文件组成：

```text
编号.md            —— 可视化教学画面，包含 Mermaid 图、要点、代码示例和 5 道选择题
编号.conversation  —— 对应的双人讲解对话，用于自动朗读、录音或录制教学视频
```

例如 `05.md` 与 `05.conversation` 内容严格对应，都围绕“Autograd：自动微分与计算图”这一主题。

## 文件编号规则

* 文件名使用两位数字编号，从 `01` 到 `30`，编号连续、不跳号
* 每组文件只讲解一个明确主题，前后章节按照“训练本质 → 核心组件 → 模型能力 →
  训练稳定性 → 工程效率 → 总结与进阶”的逻辑顺序展开

## `.md` 与 `.conversation` 的对应关系

* `.md` 文件中出现的所有图形节点、代码要点和结论，`.conversation` 都会用口语化的
  双人对话方式逐一讲解
* `.conversation` 不会提前讲解后续章节内容，也不会在对话中公布本章选择题答案
* 每个 `.conversation` 结尾都会自然提醒学习者：本章教学已结束，可以去完成章节末尾的
  5 道选择题

## 推荐播放顺序

建议按照编号顺序从 `01` 到 `30` 依次学习：先看/听 `.conversation` 讲解，
再对照 `.md` 中的图形和代码回顾要点，最后完成本章末尾的 5 道选择题。

## 每章选择题说明

* 每个 `.md` 文件末尾固定包含 **5 道单项选择题**，覆盖本章核心概念、流程顺序、
  组件职责、实际应用场景和综合理解等不同层次
* 每道题有且只有一个正确答案，并配有教学解析
* 在学习者选择答案之前，正确答案和解析不会提前显示

## 选择题数据块的读取方式

每个 `.md` 文件末尾都包含一段 HTML 注释包裹的机器可读数据块：

```markdown
<!-- QUIZ_DATA_START
{
  "chapter": "05",
  "questions": [ ... 5 道题的完整结构化数据 ... ]
}
QUIZ_DATA_END -->
```

本地 Python 播放器或网页播放器可以按如下方式解析：

```python
import re
import json

with open("05.md", encoding="utf-8") as f:
    content = f.read()

match = re.search(r"QUIZ_DATA_START\s*(\{.*?\})\s*QUIZ_DATA_END", content, re.S)
quiz_data = json.loads(match.group(1))
```

`quiz_data["questions"]` 中每道题都包含 `question`、`options`（A/B/C/D）、
`answer`（A/B/C/D 之一）和 `explanation` 四个字段，JSON 可以被 `json.loads()` 正常解析。

## GitHub 静态查看方式

如果直接在 GitHub 上浏览 `.md` 文件，选择题的正确答案和解析被放在
`<details><summary>` 折叠区域中，需要手动点击展开查看。

**普通 GitHub Markdown 只能通过折叠区域查看答案，不能自动判定用户选择。**
**如需实现点击选项后自动判断正误并显示答案，需要由课程播放器读取 QUIZ_DATA
数据块并实现交互逻辑。**

## 课程播放器互动答题方式

支持互动功能的课程播放器应当实现以下流程：

```text
显示题目与 A/B/C/D 四个选项
    ↓
等待学习者点击一个选项并锁定选择
    ↓
读取该题的 QUIZ_DATA，判断选择是否正确
    ↓
显示“回答正确/回答错误”，标记学习者选择的选项和正确选项
    ↓
显示正确答案字母、内容及答案解析
    ↓
允许学习者进入下一题（每题只允许提交一次）
```

在学习者点击选项之前，播放器不应显示正确答案，也不应通过样式提示正确选项。

## 答题得分规则

* 每章满分为 5 分，每道题 1 分
* 完成 5 道题后，播放器应显示：`本章得分：X / 5`，`正确率：XX%`
* 建议反馈标准：

  | 得分 | 反馈 |
  |---|---|
  | 5 分 | 本章知识掌握得很好 |
  | 4 分 | 整体掌握良好，可以复习答错的知识点 |
  | 3 分 | 已经理解主要内容，建议重新查看本章重点 |
  | 0～2 分 | 建议重新学习本章后再次答题 |

答题反馈应当客观、鼓励学习，不使用讽刺、贬低或羞辱性语言。
