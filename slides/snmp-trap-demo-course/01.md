# 01 项目背景：为什么要做一个SNMP Trap监控演示

本章说明这套演示系统要解决的问题，以及它的适用范围和边界。

```mermaid
flowchart LR
    P[问题] --> Q[如何验证从设备事件<br/>到可视化告警的完整链路]
    Q --> R[目标]
    R --> S[用最小可运行的方式<br/>跑通接收 转发 存储 展示]
```

## 核心要点

* 该项目模拟 IoT 设备通过 SNMP v2c Trap 上报事件，用来学习和验证从设备端到 Web 展示端的完整链路。
* 覆盖范围是三类事件：NORMAL（正常）、TEMPERATURE_HIGH（温度过高）、DEVICE_ERROR（设备错误），均为单节点演示。
* 明确不包含的内容：SNMPv3、Inform 确认机制、轮询、MIB 分发系统、认证授权、消息队列、集群冗余、告警通知、数据修改和删除页面。
* 整体技术栈：Java 21 + SNMP4J 负责发送，Net-SNMP 的 snmptrapd 负责接收，Spring Boot 负责业务处理，Oracle Database Free 负责持久化。

---

## 本章测验

本章共 5 道单项选择题。

### 第 1 题

这套 SNMP Trap 演示系统覆盖的业务事件类型是哪三种？

- A. ONLINE、OFFLINE、UNKNOWN
- B. NORMAL、TEMPERATURE_HIGH、DEVICE_ERROR
- C. INFO、WARNING、ERROR
- D. START、RUNNING、STOP

<details>
<summary>选择答案后查看结果</summary>

正确答案：B

答案解析：项目明确定义了三类事件：NORMAL（正常）、TEMPERATURE_HIGH（温度过高）、DEVICE_ERROR（设备错误），这是整个演示的业务范围。

</details>

### 第 2 题

以下哪一项属于该项目明确声明不包含的内容？

- A. Web 页面展示
- B. SNMPv3 与 Inform 确认机制
- C. SNMP v2c Trap 发送
- D. Oracle 数据持久化

<details>
<summary>选择答案后查看结果</summary>

正确答案：B

答案解析：项目范围明确排除了 SNMPv3、Inform、轮询、MIB 分发、认证授权、消息队列、集群冗余、告警通知等内容。

</details>

### 第 3 题

该项目使用的数据持久化组件是什么？

- A. MySQL
- B. Oracle Database Free
- C. MongoDB
- D. Redis

<details>
<summary>选择答案后查看结果</summary>

正确答案：B

答案解析：项目使用 Oracle Database Free（FREEPDB1）来保存接收到的 Trap 事件数据。

</details>

### 第 4 题

负责发送 SNMP Trap 的组件使用了什么技术组合？

- A. Go 加 gosnmp
- B. Node.js 加 net-snmp
- C. Python 加 pysnmp
- D. Java 21 加 SNMP4J

<details>
<summary>选择答案后查看结果</summary>

正确答案：D

答案解析：IoT Simulator 由 Java 21 编写，使用 SNMP4J 库来构造和发送 SNMP v2c Trap。

</details>

### 第 5 题

为什么在项目一开始就要明确列出“不包含”的功能范围？

- A. 因为这些功能会导致程序报错
- B. 因为这些功能技术上无法实现
- C. 为了防止学习者把演示项目误当成可直接上生产的系统
- D. 为了减少代码量，与理解无关

<details>
<summary>选择答案后查看结果</summary>

正确答案：C

答案解析：演示类项目最容易被误解为生产级方案，提前划清边界能帮助学习者建立正确预期，避免后续产生误解。

</details>
