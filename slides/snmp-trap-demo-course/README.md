# SNMP Trap Demo 课程包（中文 · 长版）

## 课程主题

本课程基于开源项目 [seki999/snmp-trap-demo20260806](https://github.com/seki999/snmp-trap-demo20260806) 制作，
讲解一套 IoT 设备通过 SNMP v2c Trap 上报事件、经 snmptrapd 接收转换、Spring Boot 校验持久化、
最终在 Oracle 数据库与网页上展示的完整链路。内容来源于该仓库的 README 以及
docs 目录下的《基本設計書》《詳細設計書》《Net-SNMP辞書・変換設計書》。

## 总章节数

共 28 组文件（01 至 28），适合完整技术课程学习，建议时长约 40～60 分钟。

## 文件使用方式与编号规则

每一章由两个同名文件组成：

```text
01.md            01.conversation
02.md            02.conversation
...
28.md            28.conversation
```

* 文件编号使用两位数字，连续不跳号。
* `.md` 文件负责展示知识结构、Mermaid 图形、核心要点和本章测验。
* `.conversation` 文件负责用两人对话的形式讲解对应 `.md` 文件的内容，格式固定为 `speaker 1:` 和 `speaker 2:`，不含任何 Markdown 标记，适合直接用于 TTS 朗读或录音。
* 两个文件严格对应同一个主题，建议按编号顺序连续播放或阅读。

## 推荐播放顺序

按 01 到 28 顺序播放即可，章节之间具有自然的学习递进关系：
从项目背景与协议基础开始，逐步深入到组件职责、数据流、辞书体系、接口与数据库设计，
最后是错误处理、变更流程、故障排查与总结。

## 每章测验说明

每个 `.md` 文件末尾固定包含 5 道单项选择题，覆盖本章的核心概念、流程顺序、组件职责、
实际应用场景以及常见误区。每道题只有一个正确答案，并配有答案解析。

### 测验数据块的读取方式

每个 `.md` 文件末尾都有一段 HTML 注释包裹的机器可读数据块：

```markdown
<!-- QUIZ_DATA_START
{
  "chapter": "01",
  "questions": [ ... 5 道题的完整结构化数据 ... ]
}
QUIZ_DATA_END -->
```

课程播放器或本地脚本可以用正则或字符串匹配提取 `QUIZ_DATA_START` 与 `QUIZ_DATA_END`
之间的内容，再用标准 JSON 解析库（如 Python 的 `json.loads()`）解析出题目、选项、
正确答案和解析，用于生成可点击的互动答题界面。

### GitHub 静态查看方式

如果直接在 GitHub 上浏览 `.md` 文件，可以看到用 `<details>` 与 `<summary>` 折叠的答案区域：
展开之前只显示题目和选项，展开之后才显示正确答案和解析。
**请注意：这只是浏览器手动展开折叠区域，GitHub 本身并不会判断你点击了哪个选项，
也不会自动给出对错反馈。** 如需实现“点击选项后自动判断正误并显示结果”的完整互动效果，
需要由课程播放器读取上面的 `QUIZ_DATA` 数据块并自行实现交互逻辑。

### 课程播放器互动答题方式

支持互动的播放器应实现以下流程：显示题目与四个选项 → 等待用户点击 →
锁定本题选择 → 判断对错 → 显示结果、正确答案与解析 → 允许进入下一题。
在用户点击之前，不应提前显示正确答案或用样式提示正确选项。

### 答题得分规则

每章满分 5 分，每题 1 分。完成 5 题后可显示得分与正确率，并给出鼓励性反馈：

* 5 分：本章知识掌握得很好
* 4 分：整体掌握良好，可以复习答错的知识点
* 3 分：已经理解主要内容，建议重新查看本章重点
* 0～2 分：建议重新学习本章后再次答题
