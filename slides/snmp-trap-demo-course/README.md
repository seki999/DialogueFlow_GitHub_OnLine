# SNMP Trap Demo 课程包

本课程基于 GitHub 项目 seki999/snmp-trap-demo20260806 制作，讲解一个 SNMP v2c Trap
端到端处理链路的演示系统：IoT Simulator → snmptrapd（字典驱动转换）→ Spring Boot → Oracle。

## 课程规模

* 总章节数：24 组
* 每组包含一个 `.md` 文件（图解 + 要点 + 5 道选择题）和一个 `.conversation` 文件（双人讲解对话）
* 长度定位：长版课程，适合完整技术学习

## 文件编号与对应关系

```text
01.md   01.conversation   项目背景与问题
02.md   02.conversation   SNMP Trap 核心概念
...
24.md   24.conversation   课程总结与延伸思考
```

每组文件编号一致、主题一一对应：`.md` 负责可视化知识和章节测验，`.conversation` 负责用双人对话讲解对应内容。

## 推荐播放顺序

按编号 01 → 24 顺序学习，前后章节具有自然的学习递进关系，建议不要跳章。

## 选择题说明

* 每个 `.md` 文件末尾固定包含 5 道单项选择题
* 每道题只有一个正确答案，并配有答案解析
* 题目按 2 道基础题、2 道理解题、1 道应用题的比例设计

### 两种查看方式

1. **GitHub 静态查看模式**：直接在 GitHub 上打开 `.md` 文件，题目下方使用 `<details><summary>` 折叠正确答案，点击展开即可查看。

   普通 GitHub Markdown 只能通过折叠区域查看答案，不能自动判定用户选择。

2. **课程播放器互动模式**：支持互动的播放器可以读取每个 `.md` 文件末尾 HTML 注释中的 `QUIZ_DATA` 结构化数据块（JSON 格式），渲染为可点击选项，在用户作答后自动判断正误、显示正确答案和解析。

   如需实现点击选项后自动判断正误并显示答案，需要由课程播放器读取 QUIZ_DATA 数据块并实现交互逻辑。

`QUIZ_DATA` 数据块格式示例：

```text
<!-- QUIZ_DATA_START
{
  "chapter": "01",
  "questions": [
    { "id": 1, "question": "...", "options": {"A":"...","B":"...","C":"...","D":"..."},
      "answer": "B", "explanation": "..." }
  ]
}
QUIZ_DATA_END -->
```

## 答题得分规则

每章满分 5 分，每题 1 分。完成后播放器可显示：

```text
本章得分：4 / 5
正确率：80%
```

反馈建议：5 分为掌握良好；4 分建议复习答错点；3 分建议重新查看本章重点；0～2 分建议重新学习本章。

## 内容依据与说明

* 第 01～21 章基于项目 README 与 `docs/详细设计書.md` 中描述的**实际实现**（SNMP v2c、单节点、无重试队列）。
* 第 23 章特别说明：仓库中还存在一份更完整的生产级设计文档（涉及 SNMPv3、多节点、持久化重试队列等），该文档描述的是**尚未实现的演进方向**，与当前 Demo 的实际行为不同，课程中已明确区分标注，不作为当前系统功能陈述。
