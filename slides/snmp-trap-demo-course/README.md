# SNMP Trap Production Platform 教学课程

## 课程主题

本课程基于开源示例项目「SNMP Trap Production Platform」（Java 21 / SNMP4J、Net-SNMP `snmptrapd`、Spring
Boot、Oracle Database 构建的生产级 SNMP Trap 接收基础设施）制作，系统讲解 SNMPv3 安全模型、Trap/Inform
接收链路、OID/VB/Trap 名称转换、持久化重试队列、认证与去重机制、Oracle 持久化、容器与 Kubernetes 生产部署、
以及测试策略。

## 总章节数

共 24 组文件（01 ~ 24），对应「长」课程格式，覆盖背景问题、核心概念、整体架构、各功能模块、安全设计、
可靠性设计、生产部署与测试策略，最后一章为课程总结。

## 文件使用方式与编号规则

每一章由两个同名文件组成，文件名统一使用两位数字编号，编号连续不跳号：

```text
01.md
01.conversation

02.md
02.conversation
...
24.md
24.conversation
```

* `编号.md`：展示本章知识结构，包含一句话问题说明、Mermaid 图形、核心要点、以及本章末尾固定的 5 道单项选择题。
* `编号.conversation`：讲解对应 `.md` 文件内容的双人对话脚本，固定使用 `speaker 1:` / `speaker 2:` 格式，
  不含任何 Markdown 标记，适合直接用于文字转语音（TTS）朗读或课程视频配音。

## `.md` 与 `.conversation` 的对应关系

两个文件严格一一对应、同名不同后缀。`.conversation` 只讲解对应 `.md` 文件里出现的图形、要点和知识点，
不提前透露后续章节内容，也不在对话中公布测验答案。

## 推荐播放顺序

按编号从 01 到 24 依次播放/阅读，前后章节按照“背景问题 → 核心概念 → 整体架构 → 各功能模块 → 安全与可靠性
设计 → 生产部署 → 测试策略 → 总结”的逻辑顺序编排，建议不要跳章学习。

## 每章测验说明

* 每个 `.md` 文件末尾固定包含 5 道单项选择题，每题 4 个选项（A/B/C/D），只有一个正确答案。
* 在学习者选择答案之前，正确答案和解析都被隐藏在 Markdown 的 `<details><summary>` 折叠区域中。
* 每题都配有简短的答案解析，帮助理解为什么该选项正确、其他选项为什么不对。
* 正确答案在 A/B/C/D 四个位置上大致均匀分布，避免规律可猜。

## 选择题数据块的读取方式

每个 `.md` 文件末尾还包含一段机器可读的结构化数据，包裹在 HTML 注释中：

```markdown
<!-- QUIZ_DATA_START
{
  "chapter": "01",
  "questions": [ { "id": 1, "question": "...", "options": {"A": "...", "B": "...", "C": "...", "D": "..."},
                   "answer": "B", "explanation": "..." }, ... ]
}
QUIZ_DATA_END -->
```

这段 JSON 可以被 Python 的 `json.loads()`（先去除注释标记）直接解析，供本地播放器或网页播放器读取题目、
选项、正确答案和解析，用来实现点击选项后的自动判题界面。本包已通过自动化脚本校验，确保所有 24 个章节的
JSON 均可被正确解析，且页面显示内容与 JSON 数据完全一致。

## GitHub 静态查看方式

普通 GitHub Markdown 只能通过 `<details>` 折叠区域手动展开查看答案，不能自动判定用户点击了哪个选项。
在 GitHub 网页上直接浏览 `.md` 文件时，选项本身是普通文本列表，学习者需要自行思考后点击“选择答案后查看结果”
展开区域来核对答案，这只是一种兼容备用的查看方式。

## 课程播放器互动答题方式

如需实现“点击选项后自动判断正误、显示正确答案和解析”的完整互动体验，需要由课程播放器读取每章末尾的
`QUIZ_DATA` 数据块并实现交互逻辑：生成可点击的选项按钮、接收点击、判断正误、显示结果与解析、记录进度、
计算得分。纯 GitHub Markdown 本身无法自动判题，必须依赖播放器程序解析 `QUIZ_DATA` 才能实现完整互动。

本课程包不包含播放器程序本身，仅提供符合规范、可被播放器解析的 `.md` / `.conversation` 内容文件。

## 答题得分规则

每章满分 5 分，每题 1 分。完成 5 道题后，建议按以下规则给出反馈：

| 得分 | 反馈 |
|---|---|
| 5 分 | 本章知识掌握得很好 |
| 4 分 | 整体掌握良好，可以复习答错的知识点 |
| 3 分 | 已经理解主要内容，建议重新查看本章重点 |
| 0～2 分 | 建议重新学习本章后再次答题 |
