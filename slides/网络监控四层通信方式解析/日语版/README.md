# TCP Ping・SNMP GET・SNMP Trap・Syslog 詳細コース

本コースは4つの監視通信方式を28章に整理した日本語版です。自動読み上げ、録音、教材動画、インタラクティブな確認問題に利用できます。各章には5問、合計140問の四択問題があります。

## 利用方法

1. `01.md` から `28.md` まで番号順に表示します。
2. 各 `.md` を表示しながら、同じ番号の `.conversation` を二人の話者で読み上げます。
3. `.md` は図、要点、章末クイズを担当し、`.conversation` は図と要点の解説を担当します。
4. 各番号には必ず `.md` と `.conversation` が1つずつあります。

## 章末クイズ

- 各章は5問、1問1点、満点は5点です。
- 各問題にはA、B、C、Dの4選択肢があり、正解は1つだけです。
- GitHubで静的に閲覧する場合は、自分で回答を決めた後に折りたたみ領域を開いて正解と解説を確認します。
- 通常のGitHub Markdownは折りたたみ領域を表示できますが、選択した回答を自動採点することはできません。
- クリック後の自動採点が必要な場合は、プレーヤーが各ファイル末尾の `QUIZ_DATA` JSONを読み取り、回答前は `answer` と `explanation` を非表示にしてください。

## 採点フィードバック

- 5点：この章の内容をよく理解できています。
- 4点：全体をよく理解しています。間違えた項目を復習しましょう。
- 3点：主な内容は理解できています。重要ポイントをもう一度確認しましょう。
- 0～2点：この章を学び直してから、もう一度挑戦しましょう。

## 技術上の前提

- 本コースのTCP Pingは、TCPポートを利用する到達性確認方法であり、独立した標準プロトコルではありません。
- TCP接続の成功は、アプリケーションや業務処理全体の正常性を保証しません。
- UDP 161、UDP 162、514、TLS 6514は代表的なポートです。実環境では機器設定、ポート変換、ファイアウォール設定を確認してください。
- 例示したポーリング間隔は設計方法を説明するための値であり、すべての本番環境に適用する固定基準ではありません。
