# TCP Ping、SNMP GET、SNMP Trap、Syslog 深度课程

本课程把四种常见监控通信方式整理为 28 个连续章节，适合自动朗读、录音、教学视频录制和互动答题。每章末尾包含 5 道单项选择题，共 140 道题。

## 使用方式

1. 按编号从 `01.md` 播放到 `28.md`。
2. 展示某个 `.md` 画面时，朗读同编号 `.conversation`。
3. `.md` 负责标题、Mermaid 图形、表格、核心要点和章节测验；`.conversation` 负责双人讲解。
4. `.conversation` 每行只包含 `speaker 1:` 或 `speaker 2:`，可交给支持双角色的朗读或录音工具。
5. Mermaid 图采用 GitHub Markdown 支持的稳定语法；建议先在目标播放器中预览。

## 章节测验

- 每个 `.md` 末尾恰好包含 5 道单项选择题，每题 1 分，满分 5 分。
- 每题包含 A、B、C、D 四个选项，并且只有一个正确答案。
- GitHub 静态查看时，先自行选择，再展开 `<details>` 区域查看答案和解析。
- 普通 GitHub Markdown 只能通过折叠区域查看答案，不能自动判定用户选择。
- 如需实现点击选项后自动判断正误并显示答案，需要由课程播放器读取 `QUIZ_DATA` 数据块并实现交互逻辑。

## QUIZ_DATA 读取方式

每个 `.md` 文件末尾都有 `QUIZ_DATA_START` 与 `QUIZ_DATA_END` 包围的 JSON。播放器应读取其中的 `chapter` 和 5 个 `questions`，在用户选择前隐藏 `answer` 与 `explanation`；用户提交一次后再显示结果、正确选项和解析。

播放器完成 5 题后应显示本章得分与正确率，并按以下规则反馈：

- 5 分：本章知识掌握得很好。
- 4 分：整体掌握良好，可以复习答错的知识点。
- 3 分：已经理解主要内容，建议重新查看本章重点。
- 0～2 分：建议重新学习本章后再次答题。

## 编号与对应关系

- 文件名统一使用两位连续编号。
- 每个编号恰好包含一个 `.md` 和一个 `.conversation`。
- 同编号文件只讲一个主题，对话按画面中的节点、箭头和要点展开。

## 课程边界

- TCP Ping 在本课程中指基于 TCP 端口的连通性检测方法，不是独立标准协议。
- 端口可连接不等于协议、应用或业务健康。
- UDP 161、UDP 162、514 和 TLS 6514 均作为典型端口讲解，实际部署必须以设备与网络配置为准。
- 示例轮询周期用于说明设计方法，不是适用于所有生产环境的固定标准。
