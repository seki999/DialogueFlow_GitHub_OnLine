# 第一个项目：账户查询实战

在不创建任何收费资源的前提下，跑通 Provider、Data Source 和 Output 的完整流程。

```mermaid
flowchart LR
    A[versions.tf] --> B[provider.tf]
    B --> C[data.tf]
    C --> D[outputs.tf]
    D --> E[tofu apply]
```

## 核心要点

* 第一个项目只查询账户信息，不创建收费资源，目录包含 versions.tf、provider.tf、variables.tf、data.tf、outputs.tf
* version = "~> 8.24" 表示只允许 8.24.x，不会自动升级到 8.25.0 或 9.0.0，比 ">= 8.0" 更安全
* provider.tf 通过 config_file_profile 读取 ~/.oci/config 中的 DEFAULT 配置
* outputs.tf 用 for 表达式从 data.oci_identity_regions.available.regions 中提取所有订阅区域名称

---

## 本章测验

本章共 5 道单项选择题。

### 第 1 题

第一个项目的目标是什么？

- A. 只查询账户信息，不创建收费资源
- B. 创建一台 Compute 实例
- C. 创建整套 VCN 网络
- D. 部署 OKE 集群

<details>
<summary>选择答案后查看结果</summary>

正确答案：A

答案解析：文中明确说明“先不创建收费资源，只查询账户信息”，这是学习 Provider、Data Source 和 Output 用法的安全起点。

</details>

### 第 2 题

version = "~> 8.24" 这种写法相比 ">= 8.0" 有什么优势？

- A. 允许自动升级到任意大版本，更灵活
- B. 只允许 8.24.x，不会自动升级到 8.25.0 或 9.0.0，更安全
- C. 两者完全等价
- D. 会强制使用最旧的版本

<details>
<summary>选择答案后查看结果</summary>

正确答案：B

答案解析：文中说明 ~> 8.24 表示允许 8.24.x 但不会自动升级到 8.25.0 或 9.0.0，对生产环境而言比 >= 8.0 更安全可控。

</details>

### 第 3 题

provider.tf 中的 config_file_profile 参数作用是什么？

- A. 指定 OpenTofu 的版本
- B. 指定 State 文件的存储位置
- C. 指定要读取 ~/.oci/config 中的哪个配置段落
- D. 指定 VCN 的 CIDR 范围

<details>
<summary>选择答案后查看结果</summary>

正确答案：C

答案解析：config_file_profile 指定读取 ~/.oci/config 中的哪个配置段（如 DEFAULT），Provider 会据此获取认证信息。

</details>

### 第 4 题

要获取当前租户订阅的所有区域名称列表，应该怎么写 output？

- A. 直接引用 var.region
- B. 写死一个固定的区域列表
- C. 使用 count.index
- D. 使用 for 表达式遍历 data.oci_identity_regions.available.regions

<details>
<summary>选择答案后查看结果</summary>

正确答案：D

答案解析：文中 outputs.tf 示例使用 for region in data.oci_identity_regions.available.regions : region.name 这样的 for 表达式提取所有区域名称。

</details>

### 第 5 题

第一个项目的执行顺序是什么？

- A. fmt → init → validate → plan → apply
- B. apply → init → plan
- C. destroy → apply
- D. validate → destroy

<details>
<summary>选择答案后查看结果</summary>

正确答案：A

答案解析：文中给出的执行顺序是 tofu fmt、tofu init、tofu validate、tofu plan、tofu apply，与标准工作流程一致。

</details>
