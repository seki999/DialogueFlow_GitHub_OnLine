# OpenTofu + OCI：从入门到精通（深度课程）

## 课程简介

本课程基于《OpenTofu + OCI：从入门到精通》技术文章重新组织而成，
覆盖从核心概念、标准工作流程、OCI 网络与 Compute 实战，到工程化（Module、State、for_each）、
生产能力（IAM、Secrets、CI）、高级能力（导入、重构、多区域、排错）的完整学习路径。

- **总章节数**：26 章
- **文件总数**：52 个章节文件（26 组 `.md` + `.conversation`）+ 本 README
- **适合场景**：自动朗读、录音、录制教学视频、互动答题、深度自学

## 文件编号与使用方式

每一章由两个同名文件组成：

```text
01.md            —— 展示知识、结构、流程图（Mermaid）和本章 5 道选择题
01.conversation  —— 讲解 01.md 内容的双人对话稿（speaker 1 / speaker 2）
```

文件编号从 `01` 到 `26` 连续排列，两位数字，不跳号。`.md` 与 `.conversation`
在知识点上严格一一对应：`.conversation` 只讲解对应 `.md` 中出现的内容，
不提前透露后续章节，也不在对话中公布测验答案。

### 推荐播放顺序

按编号从 `01` 到 `26` 顺序播放/朗读即可，章节之间具有自然的学习递进关系
（入门概念 → OCI 基础资源 → 工程化实践 → 生产能力 → 高级能力 → 课程总结）。

## 每章包含 5 道选择题

每个 `.md` 文件末尾都有“本章测验”部分，固定包含 5 道单项选择题，
每题 4 个选项（A/B/C/D），只有 1 个正确答案，并配有答案解析。
正确答案在 A/B/C/D 四个字母上的分布经过整体调平，避免所有题目答案集中在同一字母。

### 方式一：课程播放器互动模式

支持互动的课程播放器可以读取每个 `.md` 文件末尾 HTML 注释中的
`QUIZ_DATA` 结构化数据块，自行渲染为可点击的选择题，实现：

- 生成选项按钮
- 接收用户点击并锁定选择
- 判断正误并显示结果
- 显示正确答案与解析
- 记录进度、计算本章得分（5 题，每题 1 分）

`QUIZ_DATA` 数据块格式示例：

```html
<!-- QUIZ_DATA_START
{
  "chapter": "01",
  "questions": [
    {
      "id": 1,
      "question": "题目内容",
      "options": {"A": "...", "B": "...", "C": "...", "D": "..."},
      "answer": "B",
      "explanation": "解析内容"
    }
  ]
}
QUIZ_DATA_END -->
```

该 JSON 使用标准双引号、无尾随逗号，可以直接被 Python 的 `json.loads()` 解析。

### 方式二：GitHub 静态查看模式

在 GitHub 网页直接查看 `.md` 文件时，题目下方使用 `<details><summary>` 折叠区域
展示正确答案和解析，学习者需要主动点击展开才能看到答案。

**重要说明**：普通 GitHub Markdown 只能通过折叠区域查看答案，不能自动判定用户选择。
如需实现点击选项后自动判断正误并显示答案，需要由课程播放器读取 `QUIZ_DATA`
数据块并实现交互逻辑。

## 答题得分规则

每章满分 5 分，每题 1 分。完成 5 题后：

```text
本章得分：X / 5
正确率：XX%
```

- 5 分：本章知识掌握得很好
- 4 分：整体掌握良好，可以复习答错的知识点
- 3 分：已经理解主要内容，建议重新查看本章重点
- 0～2 分：建议重新学习本章后再次答题
