# Load Balancer

客户端的请求是怎么被分发到多个后端的？

```mermaid
flowchart LR
  Client --> Listener["HTTP :80"] --> BackendSet["ROUND_ROBIN"] --> Health["Health Check /"] --> Compute
```

## 核心要点

* Load Balancer 把客户端连接分发到多个后端，通过健康检查剔除异常后端，位于 Internet 与 Compute 之间，对应 AWS ALB/NLB、Azure Load Balancer/Application Gateway
* 使用的资源包括 `oci_load_balancer_load_balancer`、backend_set、backend、listener，主要参数是 Public/Private、Subnet、灵活带宽、协议/端口、策略、健康检查
* 创建顺序是 LB → Backend Set → Listener/Backend；本项目使用 HTTP 仅作学习用途，生产环境需要额外设计证书、HTTPS Listener、重定向、WAF；默认禁用以避免费用

## 本章测验

本章共 5 道单项选择题。

### 第 1 题

Load Balancer 的核心作用是什么？

- A. 直接存储客户端上传的文件对象
- B. 为 Private Subnet 提供访问 OCI 服务的内网路径
- C. 把客户端连接分发到多个后端，并通过健康检查剔除异常后端
- D. 自动为数据库生成备份

<details>
<summary>选择答案后查看结果</summary>

正确答案：C

答案解析：文档定义 Load Balancer 的作用是分发客户端连接到多个 Backend，并用 Health Check 剔除异常 Backend。

</details>

### 第 2 题

创建 Load Balancer 涉及的资源类型不包括以下哪一项？

- A. oci_load_balancer_load_balancer
- B. backend_set
- C. listener
- D. oci_dns_zone

<details>
<summary>选择答案后查看结果</summary>

正确答案：D

答案解析：oci_dns_zone 属于 DNS 模块，Load Balancer 涉及的是 oci_load_balancer_load_balancer、backend_set、backend、listener 这几类资源。

</details>

### 第 3 题

按照文档给出的顺序，Load Balancer 相关资源应该按照什么顺序创建？

- A. LB → Backend Set → Listener/Backend
- B. Listener → LB → Backend Set
- C. Backend → LB → Listener → Backend Set
- D. 完全没有固定顺序，可以任意创建

<details>
<summary>选择答案后查看结果</summary>

正确答案：A

答案解析：文档明确给出创建顺序：LB → Backend Set → Listener/Backend，删除时则是相反的顺序。

</details>

### 第 4 题

本项目使用 HTTP 而非 HTTPS 的原因，以及对生产环境的建议是什么？

- A. 因为 OCI 完全不支持配置 HTTPS Listener
- B. 本项目的 HTTP 仅用于学习，生产环境需要额外设计证书、HTTPS Listener、重定向和 WAF
- C. 因为 HTTPS 在任何场景下都比 HTTP 慢，所以不推荐使用
- D. 因为证书配置在 OpenTofu 中不存在对应资源，无法实现

<details>
<summary>选择答案后查看结果</summary>

正确答案：B

答案解析：文档明确说明“本 Lab 的 HTTP 是学习用，生产环境需要设计 Certificate、HTTPS Listener、Redirect、WAF”，这是对学习用途和生产实践的重要区分。

</details>

### 第 5 题

为什么本项目默认禁用 Load Balancer？

- A. 因为 Load Balancer 目前在 OCI 中还处于测试阶段，尚未正式发布
- B. 因为 Load Balancer 与 Compute 模块存在语法冲突
- C. 因为可能产生时间、带宽、数据传输相关的费用
- D. 因为 Load Balancer 只能在特定操作系统上运行

<details>
<summary>选择答案后查看结果</summary>

正确答案：C

答案解析：文档提到 Load Balancer 可能产生时间、带宽、Data Transfer 的费用，因此和 Compute、Database 等一样被列为默认禁用的资源。

</details>
