# OpenTofu × OCI 深度实践课程（opentofu-oci-learning-lab）

本课程共 30 组文件（30 个 `.md` + 30 个 `.conversation`），源自开源项目 [seki999/opentofu-oci-learning-lab](https://github.com/seki999/opentofu-oci-learning-lab)，系统讲解 OpenTofu 语法与生命周期、OCI 核心概念，以及该实验室中实现的全部 OCI 服务模块。

## 文件编号规则

* 文件名统一使用两位数字编号，例如 `01.md` / `01.conversation`
* 编号连续，从 01 到 30
* 每组文件只讲解一个明确主题，前后章节具有自然的学习顺序

## `.md` 与 `.conversation` 的对应关系

* `编号.md`：展示本章知识结构，包含 Mermaid 图、核心要点、5 道单项选择题（含折叠答案与解析）
* `编号.conversation`：讲解对应 `.md` 文件内容的双人对话，采用 `speaker 1:` / `speaker 2:` 格式，可直接用于 TTS 朗读
* 两者内容严格对应，`.conversation` 不会提前公布测验答案

## 推荐播放顺序

按文件编号从 01 到 30 依次学习。每章建议先阅读/收听 `.conversation` 讲解，再查看对应 `.md` 中的图形与要点，最后完成本章的 5 道选择题。

## 每章选择题

* 每章固定包含 5 道单项选择题，选项为 A/B/C/D，且只有一个正确答案
* 正确答案在全部章节中的分布是均衡轮转的，不会集中在同一个字母
* 在 GitHub 等静态 Markdown 环境下，正确答案与解析被放在 `<details>` 折叠区域内，需要先自行作答再展开查看

## 选择题数据块的读取方式

每个 `.md` 文件末尾都包含一段 HTML 注释包裹的机器可读数据块：

```
<!-- QUIZ_DATA_START
{ "chapter": "01", "questions": [ { "id": 1, "question": "...", "options": {"A": "...", "B": "...", "C": "...", "D": "..."}, "answer": "B", "explanation": "..." } ] }
QUIZ_DATA_END -->
```

课程播放器可以解析这段 JSON（例如 Python 的 `json.loads()`），读取题目、选项、正确答案和解析，用于渲染可点击的互动选择题。

## GitHub 静态查看方式

普通 GitHub Markdown 只能通过 `<details>` 折叠区域查看答案，不能自动判定用户的实际点击选择。

## 课程播放器互动答题方式

如需实现“点击选项后自动判断正误并显示答案和解析”，需要由课程播放器读取 `QUIZ_DATA` 数据块并自行实现交互逻辑：生成选项按钮、接收点击、判断答案、显示结果、记录进度。

## 答题得分规则

每章满分 5 分，每题 1 分。完成 5 题后：

```text
本章得分：4 / 5
正确率：80%
```

* 5 分：本章知识掌握得很好
* 4 分：整体掌握良好，可以复习答错的知识点
* 3 分：已经理解主要内容，建议重新查看本章重点
* 0～2 分：建议重新学习本章后再次答题

## 课程来源与免责说明

本课程内容基于源项目 README 及 docs 目录下的全部文档整理生成，源项目本身是学习用的小规模 IaC 实验室，不是生产模板；默认配置也会创建真实 OCI 资源，实际操作前请务必执行 `tofu plan` 并确认最新价格、Free Tier 与配额情况。
