# OpenTofu 常用命令

从 init 到 destroy，一套安全的执行流程应该怎么走？

```mermaid
flowchart LR
  Init["tofu init"] --> Fmt["tofu fmt -check -recursive"] --> Validate["tofu validate"]
  Validate --> Plan["tofu plan -out=tfplan"] --> Show["tofu show tfplan"]
  Show --> Apply["tofu apply tfplan"] --> Output["tofu output"]
  Output --> PlanDestroy["tofu plan -destroy"] --> Destroy["tofu destroy"]
```

## 核心要点

* 所有命令都在 `environments/dev` 目录下执行；`init` 获取 Provider/Module 并准备 Lock 文件，不改变 OCI 资源；`validate` 检查 HCL、类型、Schema、模块连接
* `plan -out=tfplan` 把差异保存为二进制文件（可能包含敏感信息），`show tfplan` 用于审查已保存的计划，`apply tfplan` 把已审查的差异发送到 OCI
* 已保存的 Plan 会和创建时的 State/配置绑定，一旦代码或 State 变化就要重新生成；学习阶段不建议使用 `-auto-approve`，应该养成先读懂差异再执行的习惯

## 本章测验

本章共 5 道单项选择题。

### 第 1 题

`tofu init` 执行后，会对 OCI 上的实际资源产生影响吗？

- A. 会，它会立即创建代码中定义的所有资源
- B. 会，它会删除所有已存在的资源
- C. 不会，它只负责获取 Provider/Module 并准备本地环境
- D. 会，它会自动修改所有资源的标签

<details>
<summary>选择答案后查看结果</summary>

正确答案：C

答案解析：文档明确说明 `tofu init` 的作用是获取 Provider/Module，准备 .terraform 目录和 Lock 文件，OCI 资源本身保持不变。

</details>

### 第 2 题

`tofu plan -out=tfplan` 生成的文件需要注意什么？

- A. 它是纯文本格式，任何人都可以安全公开分享
- B. 它会自动上传到公共 Registry 供他人下载
- C. 它与 State 文件完全无关，不需要额外注意
- D. 这是一个二进制 Plan 文件，可能包含敏感信息

<details>
<summary>选择答案后查看结果</summary>

正确答案：D

答案解析：文档提醒保存的 Plan 是 Binary 格式，且“可能包含秘密信息”，需要像对待 State 一样谨慎处理，不能随意公开分享。

</details>

### 第 3 题

已保存的 Plan 文件（tfplan）什么情况下需要重新生成？

- A. 当代码或 State 发生变化之后
- B. 每天固定在同一时间自动重新生成一次，与内容变化无关
- C. 只有在切换操作系统时才需要重新生成
- D. Plan 文件一旦生成就永久有效，不需要重新生成

<details>
<summary>选择答案后查看结果</summary>

正确答案：A

答案解析：文档明确说明“保存 Plan 与创建时刻的 State/Configuration 绑定，代码或 State 变化后需要重新制作”，这是理解 Plan 文件生命周期的关键。

</details>

### 第 4 题

为什么学习阶段不建议使用 `-auto-approve`？

- A. 因为这个参数在 OpenTofu 中根本不存在
- B. 因为它会跳过人工审查环节，不利于养成阅读差异的习惯
- C. 因为它只能在 destroy 命令中使用，不能用于 apply
- D. 因为使用它会导致所有资源立刻被删除

<details>
<summary>选择答案后查看结果</summary>

正确答案：B

答案解析：文档提到“`-auto-approve` は学習時に使わず、差分を読む習慣を優先します”，说明这是从学习习惯角度给出的建议，而不是技术限制。

</details>

### 第 5 题

在这套安全流程中，`tofu show tfplan` 起到什么作用？

- A. 直接把 Plan 应用到 OCI 上，跳过审查环节
- B. 永久删除已保存的 Plan 文件
- C. 把已保存的二进制 Plan 转换成人类可读的形式，供审查使用
- D. 用于查询 OCI 账户的当前余额

<details>
<summary>选择答案后查看结果</summary>

正确答案：C

答案解析：文档说明 `tofu show tfplan` 是“将保存的 Plan 用人类可读的方式展示”，用于在正式 apply 之前进行审查，本身不会修改任何资源。

</details>
