# 01 从监控问题到模块化单体

建立课程全景：这个系统解决什么问题，以及为什么它不是微服务集合。

```mermaid
flowchart LR
    A["网络设备"] --> B["多协议输入"]
    B["多协议输入"] --> C["统一处理"]
    C["统一处理"] --> D["事件与告警"]
    D["事件与告警"] --> E["运维页面"]
```

## 核心要点

- 后端是基于 Spring Boot 的服务器端渲染模块化单体监控系统。
- Syslog、SNMP Trap、SNMP GET 和 TCP 端口检查是四类主要输入。
- 多种协议最终进入统一业务处理，而不是各自维护一套告警逻辑。
- 系统以一个主要应用、统一数据库和统一领域模型工作。
- Visual Explorer 是独立的 Vue 教学站，浏览器内模拟不等于后端真实运行。

## 实现边界

- 不要把模块化单体误称为已拆分完成的微服务。
- 不要把教学站中的模拟操作当成真实设备或云环境操作。
