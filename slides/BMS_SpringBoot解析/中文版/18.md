# 18 SNMP GET 主动查询与错误分类

理解主动查询如何构造请求、重试并把结果标准化。

```mermaid
flowchart LR
    A["目标与 OID"] --> B["SNMP v2c 配置"]
    B["SNMP v2c 配置"] --> C["PDU.GET"]
    C["PDU.GET"] --> D["发送与等待"]
    D["发送与等待"] --> E["结果分类"]
    E["结果分类"] --> F["IngestRequest"]
```

## 核心要点

- SnmpV2cQueryClient 创建 UDP Transport、目标、community、超时和重试配置。
- 客户端构造 PDU.GET 并加入需要查询的 OID。
- 结果区分 TIMEOUT、SNMP_ERROR、INVALID_ADDRESS 和 IO_ERROR。
- 结果记录成功状态、OID、值、耗时、错误和重试次数。
- SnmpQueryClient 接口允许未来增加 v3 实现，但当前真实实现仍是 v2c。

## 实现边界

- 接口可扩展性不等于 SNMPv3 已实现。
- 重试次数需要有限制，不能无限阻塞调度任务。
