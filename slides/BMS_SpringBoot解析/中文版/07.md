# 07 列表、详情、分页与安全排序

理解管理后台怎样生成可浏览、可排序且查询边界清晰的页面。

```mermaid
flowchart LR
    A["查询参数"] --> B["Controller"]
    B["Controller"] --> C["Service 白名单"]
    C["Service 白名单"] --> D["Page 数据"]
    D["Page 数据"] --> E["列表或详情模板"]
```

## 核心要点

- 列表页由 Controller 接收页码、大小和排序参数。
- Service 使用排序字段白名单，避免任意字段被拼入查询。
- Repository 返回 Page，模板生成行、分页链接和当前状态。
- 详情页按标识查询单个领域对象，不存在时走统一 404 处理。
- 列表负责概览，详情负责完整属性与相关操作，两者职责不同。

## 实现边界

- 排序参数来自用户输入，必须限制在允许字段内。
- 分页 UI 不应把全部数据库记录一次加载到浏览器。
