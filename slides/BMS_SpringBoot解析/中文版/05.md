# 05 Fragment 与公共页面骨架

理解公共布局如何减少导航、页头和脚本的重复。

```mermaid
flowchart LR
    A["公共 Fragment"] --> B["页面参数"]
    B["页面参数"] --> C["内容片段"]
    C["内容片段"] --> D["布局组合"]
    D["布局组合"] --> E["一致页面"]
```

## 核心要点

- Thymeleaf Fragment 可复用页头、导航、消息区域和脚本引用。
- 业务页面只提供当前页面主体与必要参数。
- 公共布局让权限导航和样式入口集中维护。
- Fragment 是服务端模板复用，不是独立前端组件运行时。
- 修改公共骨架会影响所有引用它的模板，因此需要回归页面。

## 实现边界

- Fragment 能复用标记，但不等同于 Vue 的响应式组件。
- 公共布局不应偷偷执行业务数据库查询。
