# 16 Syslog 接收、解析与失败保留

理解 UDP/TCP 接收器的生命周期、解析边界和错误数据去向。

```mermaid
flowchart LR
    A["UDP 或 TCP 5514"] --> B["SyslogReceiver"]
    B["SyslogReceiver"] --> C["SyslogParser"]
    C["SyslogParser"] --> D["RFC3164 或 RFC5424"]
    D["RFC3164 或 RFC5424"] --> E["IngestRequest"]
    E["IngestRequest"] --> F["Event"]
```

## 核心要点

- SyslogReceiver 是 Spring 管理的 SmartLifecycle 后台组件。
- 默认同时监听 UDP 5514 与 TCP 5514，生产可映射标准端口 514。
- UDP 一 Datagram 一消息，TCP 按行读取并可交给虚拟线程处理连接。
- SyslogParser 支持 RFC3164 与 RFC5424，并解析 PRI、Facility、Severity 等。
- 解析失败会保留 rawMessage 并形成 syslog-parse-error Event，而不是静默丢弃。

## 实现边界

- UDP 没有应用层重传保证，慢数据库会带来接收风险。
- 接收异常被隔离不代表可以忽略监控与容量规划。
