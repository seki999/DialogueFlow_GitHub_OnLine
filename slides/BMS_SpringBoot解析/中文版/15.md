# 15 Event、Alert 与生命周期

区分不可变事实与持续故障，并理解确认、恢复和关闭的不同含义。

```mermaid
flowchart LR
    A["多次 MonitoringEvent"] --> B["按设备与 alertKey 聚合"]
    B["按设备与 alertKey 聚合"] --> C["活动 Alert"]
    C["活动 Alert"] --> D["ACKNOWLEDGED"]
    D["ACKNOWLEDGED"] --> E["RECOVERED"]
    E["RECOVERED"] --> F["CLOSED"]
```

## 核心要点

- MonitoringEvent 表示一次发生的事实，保留原始报文、状态和时间。
- Alert 表示一段持续故障，可由多个相同设备与 alertKey 的 Event 聚合。
- ACKNOWLEDGED 表示操作员已接管，不表示设备恢复。
- RECOVERED 表示监控恢复，但业务流程不一定已经正式结束。
- CLOSED 是人工确认后的正式关闭，服务会阻止关闭状态倒退到确认。

## 实现边界

- 确认、恢复和关闭是三个不同语义。
- 告警状态变化不应改写已经发生的 Event 事实。
