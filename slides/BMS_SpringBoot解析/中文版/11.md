# 11 错误页、少量 JavaScript 与国际化

理解 SSR 页面中异常、渐进增强和显示语言分别由谁负责。

```mermaid
flowchart LR
    A["请求或脚本"] --> B["服务器处理"]
    B["服务器处理"] --> C["错误映射或页面模型"]
    C["错误映射或页面模型"] --> D["模板"]
    D["模板"] --> E["本地增强"]
```

## 核心要点

- 统一异常处理把未找到等错误映射到明确的错误页面和状态码。
- 少量原生 JavaScript 用于图表或交互增强，不承担核心业务事实。
- 页面在 JavaScript 不可用时仍应保留主要信息和服务端操作。
- 显示语言来自模板文案和消息资源，需与用户要求保持一致。
- 复杂动画与架构实验由独立 Visual Explorer 承担，管理 UI 保持直接。

## 实现边界

- 错误页面不能把堆栈、密钥或内部配置暴露给用户。
- 前端脚本模拟的数据不能冒充后端生产状态。
