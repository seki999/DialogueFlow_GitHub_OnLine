# 21 PostgreSQL 与 Oracle Profile

理解双数据库支持是运行时择一，而不是同一事务同时写入两库。

```mermaid
flowchart LR
    A["启动 Profile"] --> B["PostgreSQL 配置"]
    B["PostgreSQL 配置"] --> C["或 Oracle 配置"]
    C["或 Oracle 配置"] --> D["单一 DataSource"]
    D["单一 DataSource"] --> E["JPA 运行"]
```

## 核心要点

- 默认 Profile 使用 PostgreSQL、HikariCP 和 PostgreSQLDialect。
- 连接用户名与密码通过环境变量注入。
- Oracle Profile 切换到 OracleDriver 与 OracleDialect，可面向 Oracle ADB。
- Oracle 模式下素材说明 Flyway 当前关闭，连接参数必须外部提供。
- 两个 Profile 是择一运行，不是同时连接两个数据库。

## 实现边界

- 支持 Oracle Profile 不等于已验证所有迁移在 Oracle 自动执行。
- 环境变量注入仍需由 Secrets 管理方案妥善提供。
