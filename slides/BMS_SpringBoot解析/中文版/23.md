# 23 Actuator、指标与优雅停机

理解进程健康、流量就绪、指标采集和终止阶段的不同信号。

```mermaid
flowchart LR
    A["应用运行"] --> B["Liveness"]
    B["Liveness"] --> C["Readiness"]
    C["Readiness"] --> D["Micrometer"]
    D["Micrometer"] --> E["Prometheus"]
    E["Prometheus"] --> F["Graceful Shutdown"]
```

## 核心要点

- Actuator 暴露 health、info、metrics 和 prometheus 等管理端点。
- Liveness 用于判断进程是否需要重启。
- Readiness 用于判断实例是否可以接收流量。
- Micrometer Prometheus Registry 输出 JVM、HTTP 和应用指标。
- Graceful Shutdown 在终止时尽量完成已有请求。

## 实现边界

- 健康端点通过不等于所有外部设备和业务流程都正常。
- 生产中应控制管理端点网络暴露和敏感信息。
