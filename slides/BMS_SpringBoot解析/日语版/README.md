# Spring Boot BMS 可視化インタラクティブ講座 日本語版

提供された Spring Boot 監視プラットフォームの技術資料を学習順に再構成した、全 27 章の日本語講座です。自動読み上げ、講義動画収録、GitHub での静的閲覧、ローカルでのインタラクティブ回答に利用できます。

## ファイル構成

- `01.md` ～ `27.md`：図、重要ポイント、実装境界、各章 5 問のクイズ、機械可読データ。
- `01.conversation` ～ `27.conversation`：同じ番号の Markdown に対応する二人対話。
- `player/`：クリック回答、採点、再回答に対応するローカルプレイヤー。
- `validate_course.py`：番号、JSON、問題、対話形式を確認する検証スクリプト。

`01` から `27` の順に、Markdown 画面を表示しながら同番号の conversation を読み上げる使い方を推奨します。

## 回答方法

通常の GitHub Markdown は、折りたたみ領域で解答を表示できますが、選択内容を自動採点できません。

クリック後に正誤、正解、解説を表示するには、プレイヤーが `QUIZ_DATA` を読み取って採点処理を実装する必要があります。本パッケージのプレイヤーは、回答前に正解を表示せず、回答後に問題をロックし、全 5 問の得点と正答率を表示します。

## プレイヤーの起動

講座ルートで次を実行します。

```powershell
python -m http.server 8000
```

その後、`http://localhost:8000/player/` を開きます。Markdown と Mermaid の描画ライブラリは CDN から読み込みます。オフラインで描画ライブラリが取得できない場合も、ローカルのクイズ処理は利用できます。

## 採点

各問 1 点、各章 5 点満点です。5 点は十分な理解、4 点は良好、3 点は要点の再確認、0～2 点は章の再学習を推奨します。

## 内容境界

- Visual Explorer は Vue 3、TypeScript、Vite のブラウザー教材であり、プロトコル、Alert、Kubernetes の操作はシミュレーションです。
- 提供資料に基づく現在のバックエンド基準は Java 25 と Spring Boot 3.5.14 です。古い Java 21 表記とは区別しています。
- 現在の実装、デモデータ、構成のひな形、本番向け提案を明示的に分けています。

## 検証

```powershell
python validate_course.py
```
