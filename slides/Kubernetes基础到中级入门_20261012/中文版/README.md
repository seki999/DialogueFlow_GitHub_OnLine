# Kubernetes 基础到中级入门：27 章中文课件

本课程根据用户提供的《Kubernetes（K8s）基础教程》及仓库中的“提示词_从技术内容生成md和对话.txt”制作，选择长版。重点回答组件为什么存在、何时工作、如何协作，而不是机械记命令。

## 文件与播放顺序

- 共 27 组章节，按 01–27 连续播放；每组为同编号 .md 与 .conversation。
- Markdown 展示图形、关键概念和测验；conversation 是相应双人讲解，可用于朗读或录制。
- 每章 20–24 条发言；每章 5 道单选题，全课共 135 道。
- 图形采用 Mermaid flowchart 或 sequenceDiagram，无动画脚本；连续章节逐步增加知识关系。
- 本目录位于 slides/ 下，可供当前仓库的课程目录识别。具体互动判题取决于播放器是否支持下述协议。
- examples/ 保存补充的完整 YAML，实验步骤.md 提供主线操作。不要一次性 apply 整个 examples/，其中包含不同主题和有前提的示例。

## 测验读取与显示

普通 GitHub Markdown 只能通过折叠区域查看答案，不能自动判定用户选择。折叠区只是静态兼容方案，无法阻止读者提前手动展开。

互动播放器需要读取每章末尾 HTML 注释中的 QUIZ_DATA_START 与 QUIZ_DATA_END 之间的 JSON。chapter 对应两位编号；questions 包含 id 1–5、question、options A–D、answer 和 explanation。可用 Python json.loads 或 JavaScript JSON.parse 解析。机器数据与页面题目、选项、答案、解析一致。

播放器应在选择前隐藏正确答案和解析，不预选、不提示答案。点击后锁定该题，显示“回答正确”或“回答错误”，标记用户选择与正确选项，展示正确答案字母、内容和解析，再允许进入下一题。每题只提交一次；如实现重新答题，应在本章全部完成后清除选择与结果并从第 1 题开始。课件包含数据，不包含新增播放器程序，也不声称现有播放器已经实现自动判题。

每题 1 分，本章满分 5 分。显示“本章得分：4 / 5”和“正确率：80%”等结果。反馈：5 分为“本章知识掌握得很好”；4 分为“整体掌握良好，可以复习答错的知识点”；3 分为“已经理解主要内容，建议重新查看本章重点”；0–2 分为“建议重新学习本章后再次答题”。

## 原文边界与补充

输入文本在第十三章 Helm 介绍的句子中截断，目录中的第十四、十五章正文未提供，多个代码和命令位置也为空。本课保留已提供概念，完整 YAML、命令、Helm 补充、整体流程和实验为教学补充，不能视作原文逐字复原。各章标注补充性质，官方依据集中在 来源与补充说明.md。

示例 nginx:1.27、nginx:1.28 和 busybox:1.37 是固定教学标签，不表示最新或生产推荐版本。课程未运行真实 Kubernetes 集群，命令与预期现象是供学习者执行的实验步骤；验证记录说明实际完成的静态检查。条件性 Ingress、存储供给和 Helm 占位路径均需匹配使用者环境。

课程不覆盖复杂故障排查、权限安全配置和高级集群运维。Secret 示例只说明敏感配置引用，持久卷示例不提供数据库复制或备份。
