# Embedding：把文字变成可以计算相似度的向量

计算机怎么判断两段文字“意思相近”？靠的不是关键词匹配，而是什么？

```mermaid
flowchart LR
    A[文本 text] --> B[Embedding Model]
    B --> C[向量 vector]
    C --> D[Cosine Similarity 余弦相似度]
    D --> E[找到语义相似文档]
```

## 核心要点

* Embedding 的基本原理是把文本通过 Embedding Model 转换成向量，例如 [0.13, -0.24, 0.71 ...]
* 利用余弦相似度（cosine similarity）计算向量之间的距离，从而找到语义相似的文档
* 不同语言可能需要使用不同的 Embedding 模型，例如 multilingual-e5、BGE、Jina Embeddings、OpenAI Embeddings、Cohere Embed
* Embedding 是连接原始文本与向量数据库之间的桥梁，是语义检索得以实现的核心机制

### 第 1 题

Embedding 的基本作用是什么？

- A. 把文本转换成图片以便展示
- B. 把文本转换成向量，以便用数学方式计算语义相似度
- C. 把文本压缩以节省存储空间
- D. 把文本翻译成另一种语言

<details>
<summary>选择答案后查看结果</summary>

正确答案：B

答案解析：本章明确说明 Embedding 是将文本映射为向量，从而支持语义相似度计算的核心机制。

</details>

### 第 2 题

判断两段文本语义是否相似，通常使用什么计算方式？

- A. 字符串完全匹配
- B. 文件大小比较
- C. 余弦相似度（Cosine Similarity）
- D. 随机数生成

<details>
<summary>选择答案后查看结果</summary>

正确答案：C

答案解析：本章提到利用余弦相似度衡量向量之间的方向接近程度，从而判断语义相似性。

</details>

### 第 3 题

向量检索相比传统关键词匹配的核心优势是什么？

- A. 检索速度一定比关键词匹配快十倍以上
- B. 完全不需要任何计算资源
- C. 只能用于英文文本，不支持其他语言
- D. 能够找到字面不同但语义相近的内容

<details>
<summary>选择答案后查看结果</summary>

正确答案：D

答案解析：本章强调向量检索比较的是语义空间中的距离，因此能够发现字面不同但含义相近的内容。

</details>

### 第 4 题

下列哪一组属于本章提到的 Embedding 模型？

- A. multilingual-e5、BGE、Jina Embeddings、OpenAI Embeddings、Cohere Embed
- B. MySQL、PostgreSQL、MongoDB
- C. React、Vue、Angular
- D. Docker、Kubernetes、Terraform

<details>
<summary>选择答案后查看结果</summary>

正确答案：A

答案解析：这些是本章列举的常见 Embedding 模型选项。

</details>

### 第 5 题

面对同时包含中文和英文的企业文档，选择 Embedding 模型时通常会优先考虑什么？

- A. 只使用纯英文模型，忽略中文内容
- B. 支持多语言的 Embedding 模型，确保不同语言映射到同一语义空间
- C. 为每种语言单独搭建一套独立的向量数据库且互不关联
- D. 放弃 Embedding，改用纯关键词搜索

<details>
<summary>选择答案后查看结果</summary>

正确答案：B

答案解析：本章提到面对多语言场景时，通常优先选用支持多语言的 Embedding 模型以保证跨语言检索效果。

</details>
