# FDE（Forward Deployed Engineer）技能地图课程

## 课程主题

本课程系统梳理 FDE（前线部署工程师）这一角色所需的完整能力地图，覆盖软件工程基础、
LLM、RAG、Agent、MCP、Eval、Observability、安全、IAM、云基础设施，以及 Business
Discovery 与 ROI 计算等业务能力，帮助学习者建立从技术到业务的完整知识体系。

## 总章节数

共 28 组文件（28 个 `.md` + 28 个 `.conversation`），编号 01 至 28。

## 文件使用方式

每个章节由一对同编号文件组成：

```text
01.md            —— 图文讲义：Mermaid 图、核心要点、5 道选择题
01.conversation  —— 双人讲解对话，speaker 1 / speaker 2 格式，适合 TTS 朗读
```

## 文件编号规则

* 统一使用两位数字编号，从 01 开始连续编号，不跳号
* 每组文件只讲解一个明确主题，按照“背景问题 → 核心概念 → 技术栈总览 → 各层技术细节
  → 安全与基础设施 → 业务能力 → 总结”的逻辑顺序编排

## `.md` 与 `.conversation` 的对应关系

同一编号的两个文件讲解同一个主题：`.md` 负责可视化呈现（图形、要点、测验），
`.conversation` 负责用双人对话的方式口语化讲解 `.md` 中的内容，两者严格一一对应。

## 推荐播放顺序

建议按编号从 01 到最后一章顺序学习：先阅读或播放 `.conversation` 音频讲解，
再对照 `.md` 中的图形和要点回顾，最后完成本章末尾的 5 道选择题自测。

## 每章选择题说明

每个 `.md` 文件末尾固定包含 5 道单项选择题，题目难度覆盖基础、理解、应用三个层次，
四个选项中只有一个正确答案，正确答案在全部章节中的字母分布经过均衡处理。

## 选择题数据块的读取方式

每个 `.md` 文件末尾包含一段 HTML 注释包裹的机器可读数据块：

```text
<!-- QUIZ_DATA_START
{ "chapter": "01", "questions": [ ... ] }
QUIZ_DATA_END -->
```

课程播放器或任何自定义程序，都可以用正则表达式提取 `QUIZ_DATA_START` 与
`QUIZ_DATA_END` 之间的内容，再用 `json.loads()` 解析成结构化数据，
每道题包含 `id`、`question`、`options`、`answer`、`explanation` 五个字段。

## GitHub 静态查看方式

在 GitHub 网页上直接打开 `.md` 文件即可查看图文内容和 Mermaid 图形渲染，
每道题的正确答案与解析被放在可折叠的 `<details>` 区域中，点击展开即可查看。

普通 GitHub Markdown 只能通过折叠区域查看答案，不能自动判定用户选择。

如需实现点击选项后自动判断正误并显示答案，需要由课程播放器读取 QUIZ_DATA
数据块并实现交互逻辑。

## 课程播放器互动答题方式

在支持互动的播放器中，题目以按钮形式展示 A/B/C/D 四个选项，用户点击后由播放器
判断对错、标记用户选择与正确选项，并展示对应的答案解析；用户点击前不会提前
显示任何答案信息，每道题只允许提交一次。

## 答题得分规则

每章满分 5 分，每题 1 分：

* 5 分：本章知识掌握得很好
* 4 分：整体掌握良好，可以复习答错的知识点
* 3 分：已经理解主要内容，建议重新查看本章重点
* 0～2 分：建议重新学习本章后再次答题
